# 모델 배포 상태

이번 New rule keyboard와 Multi operator keyboard 조건은 **정책 rollout 평가 대기**다. 새 최종 가중치는 아직 배포하지 않는다.

시드 101의 학습 완료 기록과 시드 100의 비교 설정은 [학습 기록](../../docs/training_status.md)에 있다. 기존 `models/final_model.pth`와 이전 모델 manifest는 이번 keyboard 조건의 결과가 아니다.
