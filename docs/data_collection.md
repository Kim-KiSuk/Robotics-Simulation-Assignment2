구성 이름은 자료를 식별하기 위한 것이다. 출처 파일 수와 실제 조작자 수를 동일하게 간주하지 않는다. 원본의 초기 상태·관측·action·성공 속성은 유지했다.

## 동작 규칙

| 규칙 | 순서 | 이번 혼합 100개 포함 |
| --- | --- | --- |
| New rule | 회전 → XY 이동 → 수직 하강 → 그립 → 수직 상승 → 박스 이동 → 릴리즈 | 포함 |
| XY 우선 | XY 이동 → 회전 → 필요 시 XY 재정렬 → 수직 하강 → 그립 → 수직 상승 → 박스 이동 → 릴리즈 | 포함 |
| 하강 우선 | 수직 하강 → 회전 → XY 이동 → 그립 → 수직 상승 → 박스 이동 → 릴리즈 | 미포함 |

파지는 수직 자세를 기준으로 한다. 상승 뒤 물체가 박스 벽보다 높게 이동할 수 있도록 한다. 제공받은 자료의 세부 동작 순서를 위 두 규칙으로 단정하지 않는다.

## 저장 형식

HDF5의 `data/demo_*`에 초기 상태·상태 관측·action이 들어 있다. action은 상대 이동 3축, 회전 3축, 그리퍼 1개인 7차원이며 제어 간격은 0.05초다. 별도 JSON이 없어도 HDF5 자체의 메타데이터와 시범을 읽을 수 있다.

정책 입력은 EE 위치·자세, 그리퍼 상태, 트럭 위치·자세, 박스 위치·자세의 23차원이다. RGB가 없는 상태 데이터는 그대로 MP4 프레임으로 변환할 수 없고 환경에서 action을 재생해 렌더링해야 한다.
