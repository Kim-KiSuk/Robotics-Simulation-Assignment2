# 문제와 가설

## 연구 질문

연구 축은 **조작자 1명 vs 다수**다. Agibot 오른팔이 트럭을 집어 박스에 놓는 Toy2Box에서, 단일 수집 구성과 여러 출처의 시범을 혼합한 구성으로 학습했을 때 성능이 달라지는지 조사한다.

| 조건 | 원본 | Annotation | Mimic 성공 시범 |
| --- | ---: | ---: | ---: |
| New rule keyboard | 20 | 17 | 1,000 |
| Multi operator keyboard | 100 | 91 | 1,000 |

이번 기록은 2026-11-01~02에 준비한 keyboard 조건이다. 기존 New rule 20·100, Multi operator 실험은 [별도 기록](experiments.md)이며 같은 실험의 평가 결과로 합치지 않는다.

## 가설과 통제 조건

| 가설 | 비교할 내용 | 필요한 통제 |
| --- | --- | --- |
| 여러 출처의 시범은 더 다양한 상태를 포함할 수 있다 | 동일 평가 조건에서 성공률과 실패 단계 | 원본 수·수집자 정보·초기 상태 분포 |
| 일정한 동작 순서는 정책이 다음 행동을 배우는 데 도움이 될 수 있다 | 회전 후 접근과 접근 후 회전의 혼합 | 동작 규칙·idle·학습 데이터 수 |
| 학습 초기화에 따라 결과가 달라질 수 있다 | 시드 101과 100 | 같은 데이터·모델·epoch·평가 조건 |

현재는 원본 수가 20개와 100개로 다르고 혼합 조건에 동작 규칙 차이도 포함된다. 따라서 조작자 수만 분리한 통제 실험은 아니다. 서로 다른 시범 파일 5개가 곧 서로 다른 사람 5명을 뜻하는 것도 아니다.

## 동작 규칙

- New rule: 회전 → XY 이동 → 수직 하강 → 그립 → 수직 상승 → 박스 이동 → 릴리즈.
- XY 우선: XY 이동 → 회전 → 필요 시 XY 재정렬 → 수직 하강 → 그립 → 수직 상승 → 박스 이동 → 릴리즈.
- 하강 우선: 수직 하강 → 회전 → XY 이동 → 그립 → 수직 상승 → 박스 이동 → 릴리즈. 이번 혼합 100개에는 미포함.

## 평가 기준

정책 rollout은 아직 수행하지 않았다. 이후 같은 평가 seed·800 step·100회 조건에서 각 trial의 성공 판정과 최종 집계를 저장한다. 1 step은 0.05초이므로 800 step은 40초다. 저장 시범의 success 속성, 증강 성공 비율, 영상 조기 종료를 정책 성공률로 바꾸지 않는다.

시드 100은 준비된 비교 설정이며 실행 완료가 확인된 모델이 아니다. [진행 현황](RESULTS.md) · [학습 기록](training_status.md)
