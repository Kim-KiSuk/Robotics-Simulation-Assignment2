# 문제와 가설

## 연구 질문

Agibot 오른팔이 트럭을 집어 상자에 놓는 Toy2Box 과업에서, 수집 원본의 동작 순서·개수·구성이 모방학습 정책에 어떤 차이를 만드는지 조사한다. 시범을 그대로 재생하는 것과 학습 정책이 새로운 관측에 따라 행동하는 평가는 서로 구분한다.

## 비교한 다섯 조건

| 조건 | 원본 | 동작 구성 | Mimic 학습 시범 |
| --- | ---: | --- | ---: |
| n100 | 100 | 기준 수집 구성 | 500 |
| New rule 20 | 20 | 회전 → XY → 하강 | 1,000 |
| New rule 100 | 100 | 회전 → XY → 하강 | 1,000 |
| Vertical | 20 | XY → 회전 → 하강 | 1,000 |
| Multi operator | 100 | 시범 파일 5개의 기존 경로를 유지해 병합 | 1,000 |

학습에는 성공 생성 시범을 사용했다. 배포 HDF5는 증강 전 원본이며 실제 수집 개수인 20개 또는 100개를 유지한다.

## 가설과 판정 범위

| 가설 | 비교 | 확인할 내용 | 현재 한계 |
| --- | --- | --- | --- |
| 접근 순서의 일관성이 행동 학습을 도울 수 있다 | New rule 20 ↔ Vertical | 같은 원본 수와 학습 수에서 정책 성공률·실패 단계 비교 | 정확한 정책 성공률 로그 미확보 |
| 원본을 늘리면 상태 분포가 넓어질 수 있다 | New rule 20 ↔ 100 | Mimic 1,000개를 유지하며 원본 수 비교 | 두 원본 사이에 겹치는 궤적이 있음 |
| 혼합 시범의 다양성과 일관성이 함께 작용할 수 있다 | New rule 100 ↔ Multi operator | 같은 원본 수·학습 수에서 비교 | idle·경로·수집 규칙과 실제 수집자 구성이 함께 달라짐 |

n100과 New rule은 원본 수뿐 아니라 Mimic 학습 개수와 정지 구성도 다르다. 이 비교를 동작 규칙 하나의 효과라고 해석하지 않는다.

## 공통 설정

| 항목 | 설정 |
| --- | --- |
| Task | `Isaac-Place-Toy2Box-Agibot-Right-Arm-RmpFlow-v0` |
| Policy | BC-RNN / GMM, LSTM hidden 400·2 layers, GMM 5 modes |
| 상태 / action | 23차원 / 7차원 |
| Sequence / batch | 10 / 100 |
| 학습 | seed 101, epoch 2000, Adam lr 0.001 |
| 평가 명령 | seed 42, 100 rollouts, horizon 800 |
| 제어 간격 | 0.05초; 800 step은 40초 |

실험별 실제 저장 설정은 [configs/experiments](../configs/experiments)에 있다. 기본 선택 모델은 `new_rule_100`의 고정 epoch 2000이다. 다른 학습 seed의 평균이나 최고 성능 checkpoint를 검증한 결과로 표기하지 않는다.

## 표본 중복과 수집자 정보

New rule 20의 20개 시범 모두 New rule 100 원본에 action·EE 위치 지문이 일치하는 궤적을 갖는다. 두 파일을 독립적인 수집 표본으로 간주하지 않는다. 이 검사는 `float32 actions + float32 obs/eef_pos`의 SHA256을 비교한 것이며, 모든 HDF5 메타데이터가 동일하다는 의미는 아니다. [검사 기록](../results/data_overlap.json)

Multi operator는 파일 5개를 합친 실험 이름이다. 원본 파일 수만으로 조작자 5명을 입증하지 않는다. 조작자 수의 영향을 연구하려면 실제 참여자를 기록하고, 사람 수 이외의 수집 규칙·원본 수·증강 수를 맞춘 별도 비교가 필요하다.

## 결과를 보고할 기준

정책의 성공률은 `play.py`의 rollout별 성공 판정과 최종 집계를 저장해 확인한다. 재생 성공, 수집 시도 성공, 영상 조기 종료를 정책 성공률로 바꾸지 않는다. 학습 seed 101·111을 각각 평가하고 접근·파지·운반·배치 실패를 구분하는 것이 추가 검증 항목이다.
